Letter burn compare

Same line, three methods. 1 = span dissolve · 2 = glyph-shaped canvas burn · 3 = pixel snapshot burn. Glow kept muted on purpose.

Method 1 · per-letter dissolve

Each character is a <span>. Staggered char + soft amber. Does not trace glyph outlines.

Method 2 · glyph-shaped burn

Glyph burn + orange heat glow + rising ash/embers from the burn front.

Method 3 · pixel snapshot burn

Whole line rasterized once, then a paper-burn front eats those pixels (holes + char + ember rim).
